MAGISTER 3.3 - PUBLICACAO NO GITHUB PAGES

1. No GitHub, crie um repositorio publico chamado magister.
2. Clique em Add file > Upload files.
3. Envie TODOS os ficheiros desta pasta, incluindo index.html, manifest.webmanifest, sw.js e icones, diretamente para a raiz do repositorio.
4. Clique em Commit changes.
5. Abra Settings > Pages > Build and deployment > Deploy from a branch.
6. Escolha branch main e pasta /(root); guarde.
7. Aguarde a publicacao. O endereco sera aproximadamente:
   https://SEU-UTILIZADOR.github.io/magister/

IPHONE: abrir o endereco no Safari > Partilhar > Adicionar ao ecra principal.
ANDROID: abrir no Chrome > menu de tres pontos > Instalar aplicacao ou Adicionar ao ecra principal.
WINDOWS: abrir no Edge > menu > Aplicacoes > Instalar este site como aplicacao. Alternativamente, use o instalador de atalho Windows fornecido separadamente.

IMPORTANTE: A aplicacao funciona offline depois de aberta online uma primeira vez. Os dados nao sincronizam automaticamente entre dispositivos. Guarde copias JSON regularmente. A publicacao num repositorio publico torna o codigo da aplicacao publico; os seus dados locais nao sao enviados para o GitHub pela aplicacao.
